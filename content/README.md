# Kuratierungsdaten

Gemeinsame Daten beider Apps: Quellenregister (`sources.json`), Risikobegriffe (`risk-terms.json`),
Startpakete (`libraries/`), Willkommensvorschläge (`welcome.json`) und das Schema (`schema/`).
Nur die Dateien aus `public-files.txt` gelangen in die App-Builds.
